## Modeling architecture

Seven tabs: Dashboard, Controls, Deal cash flow, Financing, Capacity, Alternatives, Guide. Five annual periods, three operating cases, three financing choices, and four capital-allocation routes. One active forecast serves the cases. The hard walk-away calculation requires Downside; Base and Upside present conditional active-case limits.

The modeled price is debt-free/cash-free enterprise value with normalized working capital. Affordability is conditional on selected financing, not a global debt/equity optimization. Annual cash constraints include residual closing liquidity and required debt service; terminal sale proceeds must not rescue the going-concern liquidity test. Opportunity-cost adjustment requires comparable, mutually exclusive routes. Detailed definitions are in the calculation map and guide.
